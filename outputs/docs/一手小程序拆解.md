# 「一手」小程序/APP 拆解报告

> 目的：搞清楚参考对象（`#小程序://一手/QXmB5ojtjQQjCTm`）到底是怎么做的，作为我们平台的模板依据。
> 资料来源：App Store 官方页与应用宝官方页的真实页面截图、官方 App 描述、一手官网（yishouapp.com / wlys.cn）、界面新闻 2026-06 报道。
> 说明：微信小程序运行时无法在本环境打开（详见文末「关于没能直接打开你的微信」），以下页面结构来自官方实拍截图，页面名与模块名与线上一致，个别细节以真机为准。

---

## 一、一句话结论

一手不是"服装商城"，而是 **"批发版选品 + 代采履约平台"**：
它把 **全国一批市场档口**（十三行、沙河、杭州、南油、意法、濮院…）搬到手机上，用 **买手选款** 解决"看什么"，用 **数据验真/销量榜** 解决"信不信"，用 **一件起批 + 现货24H发 + 慢必赔/断货赔付** 解决"敢不敢下单"，最后用 **自营仓 + 代采** 完成履约。

所以它的首页**不是电商那种"逛商品"**，而是：**频道（订阅/爆款榜/尾货/补贴）→ 市场档口入口 → 运营专区 → 商品流**。

## 二、信息架构（真实结构）

### 底部 5 个 Tab

| Tab | 真实名称 | 作用 |
| --- | --- | --- |
| 1 | **专场** | 首页/活动专场，即默认落地页 |
| 2 | **分类** | 品类分类（连衣裙、T恤、套装…） |
| 3 | **直播** | 档口直播拿货 |
| 4 | **进货车** | 进货单（购物车），带角标数量（截图里是 9/10 件） |
| 5 | **我的** | 账户、认证、订单、售后等 |

> 注意：**不是"购物车"而是"进货车"**，不是"首页"而是"专场"——批发语境下的用词差异，我们照抄。

### 首页顶部频道 Tab（横向可滑，尾部「☰ 全部」展开）

`订阅(NEW)` · `首页` · `爆款榜` · `新入驻档口` · `内睡专区` · `尾货` · `宝藏档口` · `限量补贴` · `男装` · `童装` · `☰ 全部`

这是它的**第二层导航**：把"运营频道"和"品类频道"混排，运营人员可以随时加减频道（尾货、限量补贴这类临时活动就是一个频道）。

### 主要二级页面（已确认存在）

新品首发（每天 7:00 上新）· 爆款榜 / 真爆款 · 限时补贴 · 档口主页 · 商品详情 · 直播（正在直播/直播预告/精彩回放）· 进货车 · 支付成功页 · 新人红包页

## 三、首页（专场）逐块拆解

从上到下共 7 块：

1. **搜索栏**：占位文案「找好货、好档口，上一手」+ 右侧 **相机（以图搜款）** + 消息入口（角标）
2. **频道 Tab 行**（见上）
3. **圆形金刚区 = 市场/档口集群**：圆形头像是"市场"，如 `十三行`、`沙河`、`杭州`、`南油`、`中纺`、`鞋包配饰`…（不是普通商城的品类图标）
4. **HOT 活动条**：`全平台满 999 包邮！平台补贴 全场通用 → 前往了解`
5. **2×2 运营大卡**（最关键的一屏）
   - `今日新款` — 夏上新·早拿早发
   - `今日特卖` — 抢先拿春特价
   - `档口现货` — 特价 3 折起 + `24H 极速发`
   - `线下真爆款` — 数据验真 + `每日更新 TOP`
6. **商品流筛选行**：`全部 | 猜你喜欢 | 沙河 | 十三行 | 杭州 | 24h ▾`
7. **双列商品瀑布流**：品牌活动图与商品卡穿插

**它的小心机**：每块都在回答店主的三个问题——"今天有什么新货"（今日新款）、"哪个便宜"（今日特卖/补贴）、"哪个好卖"（线下真爆款）。

## 四、几个关键频道/页面的做法

### 1. 新品首发（每天 7:00）
- 顶部橙色渐变头 + `每天 7:00 海量上新` + `6114 款上新`
- **日期条**：`20 21 22 23 24 25 [今日]`（按日期回看每日上新，制造"每天都要来看"的习惯）
- 分类胶囊：`全部 / 同步上新 / 休闲裤 / 牛仔裤 / 连衣裙…`
- 筛选行：`只看订阅档口 | 市场▾ | 销量 | 批发价⇅ | 筛选▾`
- 商品卡：收藏心、视频角标、`无理由退` `⚡发货快` 标签、档口名、价格 `¥70`、`今日已拼18件`

### 2. 爆款榜 / 爆款挖掘机（信任感的核心）
- 深红金色调，标题 `HOT SELECT · 档口开单系统·真爆款`
- 副标 `数据平台已验真 | 近 3 天/7 天爆款 TOP5`
- **视频验真卡**：`「档口线下真爆款」的商品验真 —— 通过查验档口开单系统数据，证明是真爆款`
- **HOT 数据验证爆款王**：`引流爆款（爆卖1000+件）` / `高搜爆款（2W+店主都在搜）` / `热销爆款（5K+大客都在拿）`
- `TOP 品类精选`：单品 TOP01/02/03
- 榜单页（iOS 版）：`TOP50 十三行实时销量榜 · 根据成交件数综合排名，实时更新`，条目里有 `最近 798 店主拿过`、`s**6 正在浏览该商品`、`去抢货` 按钮

> 这一套是拿"别人的成交数据"给新品做背书，解决批发最大的问题：**看不见货，凭什么信你**。

### 3. 限时补贴
- 头部：`限时 Sale 限时补贴 5 折起 · 官方限时限量补贴汇集区`
- 三个补贴入口：`时尚爆款 / 热卖跑量 / 好卖质感`
- 商品卡左下角统一挂 `限量补贴 低至 ¥XX/件`
- 排序：`综合 | 销量 | 上新 | 批发价⇅ | 筛选▾`

### 4. 直播（第三个 Tab）
- 三个子 Tab：`正在直播 / 直播预告 / 精彩回放`
- 直播卡：封面 + `直播中 · N 人观看` + 档口/主播 + `41 件商品` + 商品缩略图带价格

### 5. 商品详情（四页签）
- 顶部：`‹` + `商品 | 评价 | 档口 | 详情` + **分享** + **下载（一键下载素材）**
- 内容：模特实拍图 + `细节拍摄` 平铺图（强调"实拍上架，面料工艺看得见"）
- 商品卡标签体系：`无理由退` `24H 发` `慢必赔` `发货快` `剩 N 件现货` `今日已拼 N 件`

### 6. 新人/支付环节
- 支付成功页 + `新人百元红包` 随机红包弹窗（`点击领取`）
- 商品列表里就有 `5 元红包` 这类标签，红包直接挂在商品上刺激首单

## 五、它的批发专属机制（普通商城抄不来的部分）

| 机制 | 一手的做法 | 为什么这么做 |
| --- | --- | --- |
| 起批量 | **一件起批，单款单色也是打包价** | 打破一批市场"5 件/10 件起"的门槛，减少压货 |
| 拼单 | 店主拼单凑量、限时拼货 | 用平台聚合量换档口低价 |
| 代发 | 一件代发 | 服务微商/主播，不用囤货 |
| 时效承诺 | 现货专区 **24H 发货**、**慢必赔**、**断货赔付** | 批发最怕"等"，时效就是竞争力 |
| 售后 | 标注权益的商品 **7 天无理由退换** | 线上看不到货，必须给退货保障 |
| 包邮 | **满 999 包邮**、平台补贴 | 提高客单价 |
| 认证 | **认证店主**才能看批发价，**拒绝散客** | 保住 B 端价格体系 |
| 选款 | **买手驻点市场**、风格组货、订阅档口 | 让店主不用自己盯市场 |
| 工具 | **以图搜款**、一键下载素材、批量下单、加购分组（分店/测款） | 店主日常经营的刚需 |
| 上游 | 货款**日结担保**、托管式经营（平台代客服/售后） | 吸引档口入驻 |
| 履约 | 广州/杭州**自营中转仓**，90% 当日入仓即发，自研 WMS | 体验护城河 |

## 六、"它是怎么做的"——技术实现推断

**客户看到的这一端（小程序/APP）**
- 微信小程序版 + iOS/Android App 双端，页面结构高度一致（顶部频道 Tab、四页签商品详情、进货车等完全对应），说明是**同一套业务后端 + 多端前端**。
- 小程序端典型做法：原生小程序（WXML/WXSS/JS）或 Taro/uni-app 跨端框架，二选一都能做出这种效果；商品流是典型的**分页瀑布流 + 骨架屏**，图片走 CDN（static1/static3.yishouapp.com 这类 OSS 域名）。
- 图片/视频素材量大 → 必须有 OSS + 图片处理（缩略图/水印）、视频转码。

**后端必须有的能力（这才是工作量所在）**
1. 商品域：档口、SPU/SKU、色码表、批发价阶梯、库存与现货标记、上架审核
2. 交易域：进货单、按档口拆单、结算、支付、退款、售后单
3. 履约域：代采单、入仓、质检、拣货、面单、物流轨迹、赔付规则（慢必赔/断货赔付）
4. 结算域：货款日结、平台佣金、补贴/红包、对账
5. 内容域：买手选款、榜单、直播、素材库
6. 用户域：店主认证、订阅关系、分组、消息通知
7. 数据域：销量/榜单（"最近 798 店主拿过"这类数据要实时算）

**它没做的**：不是通用商城（没有复杂促销引擎），没有做 C 端零售，价格体系只面向 B 端。

## 七、对我们平台的 8 条直接结论

1. **底部 Tab 照抄**：专场 / 分类 / 直播 / 进货车 / 我的（用词都要一致）。
2. **首页照抄骨架**：搜索(含图搜) → 频道 Tab → 圆形市场入口 → HOT 活动条 → 2×2 运营卡 → 筛选行 → 瀑布流。
3. **必须有"今日新款/今日特卖/档口现货/线下真爆款"这四张卡**，它们承担首屏的全部说服工作。
4. **商品卡标签体系必须一致**：`无理由退 / 24H发 / 慢必赔 / 剩N件现货 / 今日已拼N件`。
5. **爆款榜是差异化杀手锏**：即使第一版拿不到"档口开单系统"数据，也要做一个"平台成交榜"版本。
6. **进货车按档口分组 + 按档口结算**（不同档口货期不同，必须拆单）。
7. **店主认证 + 拒绝散客**是第一版就要有的口子，否则批发价体系会崩。
8. **"每天 7:00 上新"要变成平台的习惯动作**，这是复访率的来源。

## 九、关于"没能直接打开你的微信"

我在这次会话里连试了 4 条路，全部被环境限制拦住，不是微信没装：

1. `cua.getState()` → 只返回 Codex 内置浏览器，本机应用清单为空（`apps: []`）
2. `cua.listApps()` → 方法不存在（本机应用接口未开放）
3. 按 computer-use 插件规范加载 `@oai/sky` → `Trusted RPC service is not configured: sky`
4. 工具检索 → 当前会话只有安全扫描与 node_repl，没有 Windows 应用自动化工具

你电脑上微信确实是开着的（进程里有 `Weixin` 和多个小程序容器进程 `WeChatAppEx`），但**这个会话没有开关能把鼠标键盘送进微信窗口**。

**最快的补齐方式（二选一）**：
- 你在微信里打开该小程序，把上面第八部分那 6 个页面各截一张图发我；
- 或者只截你最在意的 2-3 页（比如进货车、商品详情价格区、我的）。

我拿到后会把这些页面的模块补进拆解文档，并把原型对应页面改成 1:1 结构。
