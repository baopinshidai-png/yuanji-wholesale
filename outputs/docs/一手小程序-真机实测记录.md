# 「一手」小程序真机实测记录

> 实测时间：2026-09-11
> 实测方式：通过 Computer Use 接管你电脑上微信的小程序窗口（`WeChatAppEx.exe` → 窗口「一手服装批发」），
> 用坐标点击逐页浏览 + 读取小程序页面元素树（真实文案），**全程只浏览，未登录、未下单、未付款、未发消息**。
> 说明：因为未登录，很多数据（拿货价、购物车商品）看不到，这本身也验证了它的一条核心规则。

---

## 一、实测确认：小程序端和 App 端不一样

| 项目 | App 端（官方截图） | 小程序端（本次实测） |
| --- | --- | --- |
| 底部 Tab | 5 个：专场 / 分类 / **直播** / 进货车 / 我的 | **4 个：专场 / 分类 / 进货车 / 我的（没有直播）** |
| 商品详情页签 | 4 个：商品 / 评价 / 档口 / 详情 | **3 个：商品 / 档口 / 详情（没有评价）** |
| 首页顶部频道 Tab（订阅/爆款榜/尾货…） | 有 | 小程序首页**未见**该行，改为"市场金刚区 + 运营卡 + 筛选行" |

**结论**：微信小程序是**精简版**（去掉了直播、评价、部分频道），更像"找货 + 下进货单"的工具。
如果我们第一版先做小程序，工作量比 App 小一圈。

## 三、实测挖出来的 9 条硬规则（这些直接决定我们的产品设计）

1. **未登录/未认证 → 只显示"建议零售价"，拿货价必须认证后才可见**
   页面上直接写着 `登录看拿货价 >`、底部常驻 `登录注册，完成认证可看拿货价`。
   → 我们的平台也必须做这个价格闸门，否则批发价体系会被散客白看。

2. **满减是挂在档口/商家身上的阶梯满减**（从满699减5 一直到满30000减1050，共 18 档）
   → 商品详情要能展示"该档口的满减阶梯"，而且是**阶梯表**不是单张券。

3. **发货时效是硬承诺**：`当前下单，09月21日未发可取消` + `24H极速发` 标签
   → 订单里要有"最晚发货时间"和"超时可取消"逻辑。

4. **退换货按品类开关**：`不支持退货` + 说明"特价让利商品、内衣、童装、鞋包配等部分品类不支持无理由退货"
   → 商品维度要有一个 `退货策略` 字段（支持/不支持 + 原因）。

5. **商品卡自带三层信息**：`今日新款`（时间）、`视频/多图`（内容）、`今日已拼N件`（热度）
   → 我们的商品卡必须带这三样，否则看起来不像批发平台。

6. **长按商品卡 = 搜相似款**（以图搜款的轻量版）
   → 交互要预留长按手势。

7. **市场名字就是流量入口**（沙河/杭州/濮院/南油/十三行/中纺/金马…），
   而且**档口 = 市场 + 档口名 + 满减政策**（例：`沙河 | 满699减5`）。

8. **会员等级体系存在**：`升级白银会员可享 淡季保级`（会员等级 + 保级规则）

9. **倒计时促销页**（`仅剩 05:42:58`）用于市场大上新这类活动页
